# LossLeaderPromo_Analysis
Proyek ini menganalisis data historis transaksi kasir (Point of Sale) Alfamart untuk mengevaluasi efektivitas strategi Promo JSM (Jumat, Sabtu, Minggu) serta mengidentifikasi risiko kebocoran margin (margin leakage) diduga akibat aktivitas pembelian borongan oleh reseller/tengkulak.
